## 4. コスト最適化戦略

### 4.1 LLM コスト削減
- **プロンプトキャッシュ活用**：システムプロンプト・食材マスタをキャッシュ層に載せる（Cache Read は Input の 1/10）。
- **モデル使い分け**：日常のレシピ提案は Haiku 4.5、凝ったメニュー生成だけ Sonnet 4.6 を任意選択に。
- **結果キャッシュ**：同一在庫×同一条件の提案結果をDB/Redisにキャッシュ（24時間TTL）。
- **バッチ処理**：近い時間帯のリクエストを束ねる（MVP外）。
- **出力最大トークン制限**：`max_tokens` を厳守、冗長な説明を禁止するプロンプト設計。

### 4.2 OCR コスト削減
- 月1,000件までは無料枠。超過分のみ課金されることを利用し、**無料枠内に収まる規模**なら実質0円。
- 明らかに食品以外のレシート（衣料品等）は事前判定で除外。

### 4.3 インフラコスト削減
- 初期は全て Free プランで起動し、**使用量の閾値アラート**（Vercel, Supabase）を設定。
- 画像は圧縮＋WebP変換、古いレシートは自動削除（例: 90日）。

### 4.4 監視
- 日次で API コスト（Anthropic 管理画面、GCP 課金レポート）を確認。
- **月次予算上限** を Anthropic 側 Usage Limits で設定（暴発保険）。
- PostHog で「1ユーザーあたりのリクエスト数」を定点観測。

## 6. まとめ

- **個人〜小規模β段階なら月額 1,000円以内** で運用可能。
- **主要コストは LLM（Claude API）**。キャッシュ戦略とモデル選択で 30〜50% 圧縮余地あり。
- Vision API は無料枠で MVP はカバー可能。
- 初期開発はツール費ほぼ無料、工数が主要コスト。
- **早期からコスト監視と上限設定を導入**し、暴発リスクを最小化する。
